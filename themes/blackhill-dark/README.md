# BLACKHILL Dark Theme Pack

Premium matte-black + deep-crimson theme for BLACKHILL OS.

## Components

- **GTK 3/4** – Application theming
- **Icons** – Custom Freedesktop icon theme (`Blackhill`) with clean, recognizable (Windows-inspired metaphors) but premium dark styling
- **Hyprland** – Window decorations, colors, blur
- **Waybar** – Status bar
- **Rofi** – Launcher
- **Kitty** – Terminal
- **Hyprlock** – Lock screen

## Color Palette

| Name              | Hex       | Usage                          |
|-------------------|-----------|--------------------------------|
| Background        | `#0A0A0A` | Main background                |
| Surface           | `#141414` | Cards, panels                  |
| Surface 2         | `#1E1E1E` | Elevated elements              |
| Border            | `#2A2A2A` | Subtle borders                 |
| Crimson           | `#8B0000` | Primary accent                 |
| Crimson Bright    | `#C41E3A` | Hover / active                 |
| Text Primary      | `#E8E8E8` | Main text                      |
| Text Secondary    | `#A0A0A0` | Secondary text                 |

## Installation

```bash
./install-theme.sh
```

Then set GTK and icon theme via gsettings or nwg-look.
