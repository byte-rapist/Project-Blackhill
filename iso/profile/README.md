# BLACKHILL Archiso Profile (Skeleton)

This directory is reserved for a future complete Archiso profile.

## Planned contents

- `packages.x86_64` — package list for the live environment
- `airootfs/` — overlay with branding, configs, and first-boot scripts
- `efiboot/` / `syslinux/` — bootloader branding
- `profiledef.sh` — Archiso profile definition

## Current guidance

Until the full profile is ready, follow the instructions in the parent `iso/README.md` and the main project installation guide to create a BLACKHILL system from a standard Arch install.
