# BLACKHILL v0.1.0-foundation — Release Notes

**Date**: 2026-08-08  
**Status**: Foundation / Pre-alpha  
**Codename**: Foundation

## Summary

This is the first complete foundation release of BLACKHILL. It delivers a professionally structured, fully documented configuration and theme project that transforms Arch Linux into a hardened, root-first, premium dark operator system.

## What you get

- Strong security defaults (sysctl, nftables, kernel recommendations, USBGuard baseline)
- Complete Hyprland-based desktop configuration
- Full Blackhill Dark visual identity (GTK, icons, terminal, lock screen, status bar, launcher)
- First-boot wizard and hardening applicator
- Professional open-source project files and documentation

## What this is not (yet)

- A standalone bootable ISO
- A package repository or set of official meta-packages
- A finished distribution with long-term binary support guarantees

Those are planned in later phases.

## How to use

Follow [docs/INSTALL.md](docs/INSTALL.md).

## Upgrade path

This is the initial foundation. Future versions will add profiles, packages, and eventually an ISO while remaining compatible with the configuration approach established here.

## Thanks

This foundation exists to give the owner of the machine maximum control, strong defaults, and a precise operator experience.
