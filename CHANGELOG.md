# Changelog

## [0.1.0-foundation] - 2026-08-08

### Added
- Complete professional project structure (LICENSE, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, VERSION, CHANGELOG)
- Full documentation set: Installation, Architecture, Hardening rationale, FAQ, Post-Install checklist, Roadmap
- Kernel hardening (sysctl) and nftables default-deny firewall
- Hardening applicator script and first-boot wizard
- Complete Hyprland ecosystem configs (hyprland, hyprlock, hypridle, hyprpaper)
- Blackhill Dark theme stack: GTK 3/4, Waybar, Rofi, Kitty, icons
- Custom Blackhill icon theme (core scalable SVGs)
- USBGuard baseline configuration
- Kernel command-line recommendations
- AppArmor guidance directory
- Tool recommendation list and packages structure
- Archiso profile skeleton
- Makefile for common tasks
- Branding (os-release, MOTD)

### Status
This release marks the completion of the **foundation** stage. BLACKHILL is now a coherent, documented, professionally organized configuration and theme project that can be applied on top of Arch Linux to produce a hardened, premium dark, root-first system.

A full custom ISO, installer, and package repository remain future work (see Roadmap).
