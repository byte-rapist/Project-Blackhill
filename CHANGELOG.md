# Changelog

All notable changes to the BLACKHILL project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/) once releases begin.

## [0.1.0-foundation] - 2026-08-08

### Added
- Initial public foundation of BLACKHILL
- Complete project structure and professional repository layout
- Hardening configurations (sysctl, nftables)
- Hardening applicator script
- Hyprland premium dark configuration
- Blackhill Dark theme (GTK 3/4, Waybar, Rofi)
- Custom icon theme (core scalable SVGs)
- Branding files (os-release, MOTD)
- Full documentation set: Architecture, Installation, Roadmap
- LICENSE (MIT), CONTRIBUTING, SECURITY, CODE_OF_CONDUCT
- Tool recommendation list
- ISO build notes

### Notes
This is a foundation / pre-alpha release. It provides a usable hardened + themed Arch configuration set. A full custom distribution ISO is planned for later phases.
