# Changelog

## [0.3.1] - 2026-08-08

### Added
- Full video playback support in `blackhill-desktop`
  - `mpv`, `ffmpeg`, `yt-dlp`
  - Complete GStreamer plugin set
  - `libva` + `libva-utils` for hardware decode
  - GPU-specific optdepends (Intel / AMD / NVIDIA)
- `docs/MEDIA.md` — media and hardware acceleration guide
- Video packages also intended for the live ISO list

### Changed
- Meta-package versions bumped to 0.3.1
- Installation guide updated for the media stack

## [0.3.0-foundation] / earlier

- Phases 0–4 foundation: hardening, UI, packaging, Archiso profile, Control Center, etc.
