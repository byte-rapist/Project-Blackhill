# BLACKHILL FAQ

## Is BLACKHILL a full Linux distribution yet?

It is currently a **foundation / pre-alpha** project. It provides hardening configurations, a premium desktop theme, branding, and documentation that turn Arch Linux into a BLACKHILL system. A custom ISO and installer are planned.

## Does it lock the user out of root?

No. Full root access for the owner is a core design principle.

## Is it more secure than stock Arch or Kali?

It ships stronger *defaults* (sysctl, firewall posture, kernel preference, theme of least surprise for security). Actual security depends on how it is maintained and used. It is not a magic bullet.

## Can I use BlackArch tools with it?

Yes. Enabling the BlackArch repository on top of a BLACKHILL-hardened Arch base is an intentional and recommended path for maximum tooling.

## Why Hyprland?

It is fast, modern, highly configurable, and well-suited to a premium dark operator aesthetic while remaining lightweight.

## Will there be an official ISO?

Yes, that is on the roadmap (Phase 4). Until then, the supported method is installing Arch and applying this repository.
